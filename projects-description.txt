These six sites are showcases, not employer projects. Below is detailed Senior Shopify Developer role + technical task scope you can use for each case study—aligned with your resume skills (Liquid, OS 2.0, Shopify Plus, Figma, React/Next, APIs, CRO, CWV).

1. Minaal — Travel commerce storefront
Role: Senior Shopify Developer — Theme Architecture & Conversion UX
Platform: Shopify / Shopify Plus · Online Store 2.0 · Liquid

What you did (technical)
Designed and implemented OS 2.0 sections for homepage heroes, bag collections, and accessory grids using Liquid + section schemas.
Built reusable components for product cards, color swatches, shipping/trust callouts, and mobile CTAs.
Translated Figma spacing/typography into theme CSS (or Tailwind/custom CSS) with responsive breakpoints.
Structured collection templates for Carry-on / Daily / Rolltop-style merchandising and comparison-friendly layouts.
Optimized PDPs for materials, specs, and convert-oriented information hierarchy.
Audited Liquid render cost, third-party scripts, and image sizes; applied responsive images / WebP-style delivery for catalog pages.
Supported CRO on discovery → PDP → ATC paths for high-intent travel shoppers.
Key tech
Shopify Plus · Online Store 2.0 · Liquid · JavaScript · Figma · Responsive Design · Core Web Vitals · CRO
